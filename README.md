# Longevity Life Academy — Google Ads Search Mockups

Live viewer: https://gitteromri-ux.github.io/longevity-life-academy-ads-deck/

A responsive, mobile-first viewer for the Longevity Life Academy Google Ads search campaign mockup deck (14 slides, 16:9). Each slide is rendered at exact original proportions on any screen.

## Features
- Exact 16:9 proportions on desktop and mobile
- Keyboard navigation (← → arrows, Home/End, F for fullscreen)
- Swipe gestures on touch devices
- Deep-link to any slide via `#N` (e.g. `#7`)
- Original PDF available for download
